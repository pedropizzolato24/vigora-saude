# Vigora — Product Context

## Product Purpose

App de monitoramento de saúde para idosos brasileiros. Dead man's switch: se o idoso não responde ao alarme, os contatos de emergência são alertados automaticamente via WhatsApp e os cuidadores recebem push no próprio app.

## Register

product

## Users

- **Primário (monitorado):** Dona Maria, 68 anos, São Paulo. Mora sozinha ou com cônjuge. Quer independência, não quer parecer fraca.
- **Secundário (comprador/cuidador):** Carlos, 43 anos. Filho adulto. Busca tranquilidade, não vigilância. Paga pela paz de espírito.

## Brand Voice

- **Cuidador:** Confiante, discreto, preciso. Reporta fatos, não interpretações. Timestamps específicos.
- **Monitorado:** Caloroso, próximo, humano. Usa o nome. Nunca robotiza, nunca infantiliza.

## Anti-references

- Não é app médico/hospitalar — nunca azul clínico + branco estéril
- Não é SaaS genérico — sem Inter + slate-900 + feature cards iguais
- Não é vigilância — sem câmera ou tracker vibes

## Strategic Principles

- Linguagem de bem-estar/segurança. Nunca médica ou terapêutica.
- Dignidade do usuário idoso — não é paciente, é pessoa com história
- O diferencial é o dead man's switch — nenhum concorrente no Brasil tem isso

## Tone

Calm + Stripe + Linear. Quieto, preciso, humano.
