# Vigora Saúde — Email Copy Prompt

## Email Types

### Transactional (automated triggers)
- Alarm responded / not responded notifications
- Check-in confirmations
- Account actions (signup, password reset, account deletion)
- Emergency alert copies

### Marketing/Lifecycle
- Onboarding welcome
- Trial expiry warnings (7-day trial)
- Feature announcements
- Re-engagement

---

## Tone by Email Type

| Type | Tone |
|---|---|
| Emergency alert | Urgent, factual, no decorative language. Subject: "[NOME] não respondeu ao alarme das 08h00." |
| Check-in confirmation | Brief, warm. "Maria respondeu. 14h32. Tudo bem." — that's the whole email. |
| Welcome | Warm but brief. Explain the single most important thing about the app. No feature dump. |
| Trial expiry warning | Honest, not manipulative. State the facts. Give the user agency. |
| Feature announcement | Lead with the human benefit, not the feature name. |

---

## Subject Line Guidance

**Transactional:**
- Always include the person's name
- Always include the timestamp or specific data
- Example: "Dona Maria respondeu às 14h32"
- Example: "⚠ Dona Maria não respondeu ao alarme das 08h00"

**Marketing:**
- Be specific — "Agora você sabe em 5 minutos" beats "Nova funcionalidade disponível!"
- Maximum 50 characters (preview on mobile)
- No clickbait — respect the reader's intelligence

---

## Structure (Marketing Emails)

```
From name: Vigora Saúde (or "Carlos da Vigora Saúde" for personal tone)
Subject: [Specific, under 50 chars]
Preheader: [Elaborates subject — 90 chars max]

---

[Opening — 1–2 sentences, personal, names the situation]

[Body — 2–3 short paragraphs. Each has one point.]

[CTA — Single button. Active verb. 2–4 words.]

---

Vigora Saúde
Perto de você. Sempre.

Se você não quiser mais receber esses emails: [desinscrever]
```

---

## Sign-off Conventions

- Formal transactional: "Equipe Vigora Saúde"
- Warm lifecycle: "Com carinho, Vigora Saúde"
- Emergency alerts: No sign-off — just the facts and the CTA

## What Never to Do

- Never use "Olá, Usuário" — always personalize with name
- Never apologize for the app's existence
- Never explain technical implementation ("nosso sistema de monitoramento detectou...")
- Never bury the key information — first sentence should be the main point
